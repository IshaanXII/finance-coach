# Personal Finance / Budgeting Coach

Use Case #20 — App

## Run
```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## Deploy
Push `app.py`, `requirements.txt`, `sample_expenses.csv` to GitHub → share.streamlit.io → `app.py`.

## Gemini key (optional)
Free at https://aistudio.google.com/app/apikey → sidebar. Works without key via rules.
